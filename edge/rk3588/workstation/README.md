# 工位物品识别

模型接收取景框内的 `64×64` 灰度图。输入为 `[N, 1, 64, 64]` 的浮点张量，像素范围为 `[0, 1]`。输出为 `[N, 3]` 的类别分数，顺序是 `empty`（空工位）、`bottle`（瓶子）、`cup`（杯子）。编译部署时使用单张图片输入。

```text
64×64 灰度图 → 3×3 卷积（8 通道）→ ReLU → 2×2 最大池化 → 展平 → 全连接（3 类）
```

卷积使用固定形状和无偏置权重，方便把这层作为自研后端的首个上板算子。训练时可以把模型输出直接交给交叉熵损失。

## 第一步 本地前向验证

在 `InnovationCompetition` 根目录运行，复用电脑上现有的 PyTorch CPU 环境。

```bash
local/venv-rknn-2.5.0/bin/python edge/rk3588/workstation/model.py
```

预期输出形状为 `(1, 3)`，并看到 `本地前向验证通过`。这一步用合成灰度图验证计算图和张量形状，分类效果在训练后用实拍照片检验。

## 实施步骤

1. 定义模型并验证本地前向，确定输入形状和类别顺序。
2. 从 COCO 2017 标注挑选瓶子和杯子图片，按标注框裁图。自采空工位图片，留出独立场地的实拍照片做最终测试，数据存放到 `local/`。[COCO 数据下载](https://cocodataset.org/#download) · [类别说明](https://docs.ultralytics.com/datasets/detect/coco/)
3. 在电脑上从头训练，检查各类别在实拍测试集上的识别结果。
4. 用训练好的权重导出 ONNX，完成官方 RKNN 编译、模拟核对和真机测试。
5. 把同一个 ONNX 导入 TPU-MLIR 的 TOP，从 `top.Conv` 开始做目标 lowering 和 CodeGen，在 3588 上验证生成的 NPU 任务与参考输出。
6. 接进拍照和 STM32 触发流程，用同一个模型展示识别闭环，并记录触发到反馈的时间。
